# Checklist: H1 Handoff & Done

## Trước khi bàn giao
- [ ] **[BLOCK]** Đủ màn trong phạm vi; đủ state theo bảng
- [ ] Component đúng design system; layout, spacing, typography, màu đúng guideline
- [ ] Nội dung chữ rõ ràng; trường hợp biên và permission đã thể hiện
- [ ] **[BLOCK]** Góp ý của Dev đã xử lý
- [ ] Frame đã ở page chính; tên frame và layer rõ ràng; link sẵn sàng
- [ ] **[BLOCK]** Đã lưu version bàn giao trên Figma; mọi link trong `delivery-summary.md` và file thiết kế UX trên repo PO ghi kèm version đó

## Tài liệu
- [ ] **[BLOCK]** Mỗi màn có ghi chú bàn giao trên Figma: điều kiện hiện state, tương tác, giới hạn chữ, điểm Dev tự quyết định
- [ ] `delivery-summary.md` đủ mục, có phần ngoài phạm vi và việc còn treo
- [ ] Biến ghi theo tên của domain; không mã màu rời; cách gọi trong code lấy từ nguồn thật
- [ ] Không có thiết kế API, dữ liệu, hoặc lựa chọn thư viện code
- [ ] Change log cuối và nội dung cập nhật task đã có; chưa tự đăng lên công cụ quản lý task khi Designer chưa yêu cầu
